# docs/manual.md — Manual de usuario

## Instalación
1. Clona el repositorio: `git clone https://github.com/Gera871/redes-wan-rojas.git`
2. Entra a la carpeta: `cd redes-wan-rojas`
3. Crea el entorno virtual: `python3 -m venv venv`
4. Actívalo: `source venv/bin/activate`
5. Instala dependencias: `pip install -r requirements.txt`
